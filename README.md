# 🧑‍💻 Финальный проект

## 📝 Основные требования

* Разработать мобильное приложение на любую тему
* В этом репозитории:
  * Сделать ветку final
  * Создать папку application (в ней должен быть код проекта)
  * Закоммитить код
  * После первого ревью исправить замечания
  * Отдельным коммитом или вместе с кодом создать папку presentation и в нее добавить презентацию

## 📱 Требования к приложению

* Приложение должно получать данные из сети
* Данные должны кешироваться
* Код написан в соответствии с современными требованиями к архитектуре iOS приложений
* Не менее 5 экранов (2 из которых на UIKit)
  * Пример: Авторизация, Список продуктов, Карточка продукта, Избранное, Профиль
  * Верстка только кодом
* Запрещено использовать внешние фреймоврки
  * Исключение: [open source от apple](https://github.com/orgs/apple/repositories)
* Тесты: unit-тесты для слоя данных и сервисов 

## 🍦 Дополнительные требования

* Git-история: логичные коммиты и ветвление
* Анимации: плавные переходы и интерактивные элементы
* Темная тема: поддержка светлой/темной темы
* Авторизация: система входа/регистрации
  * Допустимо реализовать локально с использованием Keychain

## 🛠 Стек технологий и рекомендации

* Xcode 26 / Swift 6 / iOS 26
* [Structured Concurrency](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/concurrency)
* [Swift API Design Guidelins](https://www.swift.org/documentation/api-design-guidelines/)
* [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines)
